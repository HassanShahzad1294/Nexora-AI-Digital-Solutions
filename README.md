# NEXORA - AI & Digital Solutions

Nexora is a modern AI and digital solutions website. I created this project to practice and improve my frontend and backend development skills.

The website has a dark modern design with purple effects and responsive layout.

## Features

- Responsive design
- Modern dark UI
- Hero section
- Solutions section
- Projects section
- About section
- Contact section
- Contact form
- MongoDB database connection
- Express.js backend
- Scroll animations
- Hover effects

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- MongoDB Atlas
- Mongoose

## Contact Form

The contact form is connected with the backend.

When a user submits the form:

User
↓
Contact Form
↓
JavaScript
↓
Express.js API
↓
MongoDB
↓
Message Saved

This allows me to receive and store client information from the website.
